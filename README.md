# Admin Panel (MERN Stack)

A simple Admin Panel to manage Categories, SubCategories, and Products.

## Tech Stack
- MongoDB
- Express
- React (Vite)
- Node.js

## How to Run

**1. Start Backend**
```bash
cd backend
npm start
```
Runs on: http://localhost:5000

**2. Start Frontend**
```bash
cd frontend
npm start
```
Runs on: http://localhost:5173
